# Student Placement Tracker

A Python-based Student Placement Management System built using Tkinter and SQLite.

## Features
- Student Registration
- Secure Login
- Add, Update and Delete Student Records
- View Student Details
- Placement Status Tracking
- SQLite Database Integration

## Technologies Used
- Python
- Tkinter
- SQLite

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python main.py

## Project Purpose
This project helps manage student information and track placement activities efficiently.
